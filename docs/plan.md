# 비교 마스터: 기술 스택 · MVP · 프로젝트 골격 (초안)

작성일 2026-10-01. 결정 전 제안서이며, 저장소 생성과 본격 코딩은 승인 후 진행합니다.

## 1. 기술 스택

| 영역 | 선택 | 이유 |
|---|---|---|
| 비교 엔진 (코어) | **Rust** | 대용량 파일·폴더 스캔 속도가 핵심 경쟁력. 같은 코드를 데스크톱(네이티브)과 웹(WebAssembly) 양쪽에 그대로 씀 |
| UI | **TypeScript + React** | 데스크톱과 웹이 UI 코드 100% 공유 |
| 텍스트 뷰/편집기 | **CodeMirror 6** | 가볍고, 수백만 줄 가상 스크롤, 병합 뷰 커스터마이즈가 쉬움 (Monaco는 무겁고 커스텀 병합 UI에 제약) |
| 데스크톱 셸 | **Tauri 2** | Electron 대비 설치 파일 ~10MB, 메모리 적음, Rust 코어를 직접 호출 |
| 웹 | 정적 SPA + WASM | 서버 없이 브라우저 안에서 비교 (파일이 외부로 안 나감). 폴더는 File System Access API, 미지원 브라우저는 드래그&드롭/zip |
| 빌드 | pnpm 워크스페이스 + Cargo 워크스페이스, Vite | 모노레포 하나로 관리 |

조정한 점: 원래 안은 "TypeScript 공용 코어 + Rust는 데스크톱 백엔드"였는데, **코어 자체를 Rust로 두고 웹에서는 WASM으로 돌리는 쪽**으로 바꿨습니다. 그래야 웹 버전도 데스크톱과 같은 속도·같은 결과를 내고, 엔진을 두 번 만들 필요가 없습니다.

## 2. Beyond Compare를 넘을 포인트 (방향성, 차차 결정)

- 압도적 속도: 수 GB 파일, 수십만 개 파일 폴더도 즉시 (병렬 스캔, 해시 캐시)
- 웹에서도 동작 (BC는 데스크톱 전용)
- 구조 인식 비교: JSON/YAML/XML 키 단위, 코드 AST 기반(tree-sitter) 비교, 이동된 블록 감지
- 똑똑한 3-way 자동 병합과 충돌 해결 보조
- Git 연동 (difftool/mergetool, 커밋 간 비교), CLI 제공
- 현대적 UI: 다크 모드, 단축키 커스터마이즈, 미니맵

## 3. MVP 범위 제안

| 단계 | 기능 | 포함 내용 |
|---|---|---|
| **MVP 1** | 텍스트 2-way 비교 | 좌우/인라인 보기, 줄 안 단어·글자 하이라이트, 공백·대소문자 무시, 차이 간 이동, 블록 복사, 편집·저장, 인코딩/줄바꿈 감지 |
| **MVP 2** | 폴더 비교 | 재귀 스캔, 크기·날짜·내용(해시) 비교, 필터(.gitignore 등), 트리 뷰, 파일 더블클릭 시 텍스트 비교로 이동, 복사/동기화 |
| **다음** | 3-way 병합 | base/left/right + 결과 창, 자동 병합, 충돌 표시와 해결 |
| 이후 | 바이너리(hex), 이미지, 표(CSV/엑셀), 구조 비교, Git 연동 | |

진행 상황 (2026-10-02): MVP 1 완료, 16진수 비교 추가, MVP 2는 재귀 스캔·크기/시각/내용 비교·제외 패턴·트리 뷰·파일 열기·복사/삭제/동기화까지 완료(남은 것은 .gitignore 필터), SourceTree·git 연동(명령줄 인수) 완료, 3-way 병합 첫 버전 완료. 폴더 스캔은 별도 `fs-scan` 크레이트 대신 `diff-core`의 `fs` 기능(데스크톱 전용)에 넣었습니다.

추천: **텍스트 비교 → 폴더 비교** 순으로 MVP를 잡고, 3-way 병합은 바로 그 다음. 텍스트 비교 엔진이 폴더 비교와 병합의 기반이라 이 순서가 가장 손실이 적습니다.

## 4. 프로젝트 골격

```
bigyo-master/
├─ crates/
│  ├─ diff-core/      # 줄/단어/글자 diff (histogram·Myers), 옵션, 3-way 병합 알고리즘
│  ├─ fs-scan/        # 병렬 폴더 스캔, 해시, 필터 (데스크톱 전용)
│  └─ diff-wasm/      # diff-core를 wasm-bindgen으로 웹에 노출
├─ packages/
│  ├─ ui/             # React 컴포넌트: DiffView, FolderTree, MergeView
│  └─ engine-api/     # UI가 쓰는 공통 인터페이스 (데스크톱=Tauri 호출, 웹=WASM 호출)
├─ apps/
│  ├─ desktop/        # Tauri 2 앱 (src-tauri는 crates 사용)
│  └─ web/            # Vite SPA
├─ Cargo.toml         # Cargo 워크스페이스
└─ pnpm-workspace.yaml
```

핵심 설계: UI는 `engine-api` 인터페이스만 알고, 실행 환경에 따라 Tauri 명령 또는 WASM으로 연결됩니다. 그래서 UI 코드는 한 벌입니다.

## 5. 첫 작업 순서 (승인 후)

1. GitHub 저장소 생성, 모노레포 골격과 CI(빌드·테스트) 구성
2. `diff-core` 줄 단위 diff + 테스트
3. 웹 앱에서 두 텍스트 붙여넣어 비교하는 최소 화면
4. 같은 화면을 Tauri 데스크톱으로 띄우기, 파일 열기
5. 단어·글자 하이라이트, 무시 옵션, 편집·저장

- MVP 범위: 위 추천(텍스트 → 폴더, 병합은 그 다음)으로 갈지
